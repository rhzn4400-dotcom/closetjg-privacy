# ClosetJG 개인정보처리방침

안드로이드 앱 **ClosetJG** 의 개인정보처리방침을 올려 두는 곳입니다.
플레이 스토어가 공개된 주소를 요구해서 이 저장소만 따로 공개해 두었습니다.

- 보이는 주소: https://rhzn4400-dotcom.github.io/closetjg-privacy/
- `index.html` 은 **앱 저장소의 빌드가 만드는 파일**입니다. 여기서 고치지 마세요.
  고칠 곳은 앱 저장소의 `app/src/main/assets/privacy_policy.html` 이고,
  빌드하면 `docs/index.html` 이 새로 만들어집니다. 그 파일을 여기에 옮겨 올립니다.
